## First Look at .NET Reflector

.NET Reflector is for people who keep .NET assemblies they own and want one named code desk, not mixed binary copies. It gives you own assemblies, .NET files, and a short path back to a project you already run. It does not replace Visual Studio. It sits beside Visual Studio and keeps the files close.

Work stays on assemblies you keep. Extra binaries wait for their own title.
